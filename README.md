# 静海AI（JingHai AI）

> 本地优先（local-first）的个人智能助手：把资料收藏、AI对话和睡前记忆提醒合在一个网页里。

## 在线体验

直接打开 `index.html` 即可使用，无需安装、无需后端、无需构建。

## 核心功能

### 1. 资料收藏管理
- 收藏链接和笔记，每条资料包含：标题、链接、正文、备注、摘要、标签
- 支持关键词搜索
- 所有数据保存在浏览器本地（localStorage），不上传任何服务器

### 2. AI 对话助手
- 在「设置」中填写自己的兼容 OpenAI 接口地址和 API Key
- 配置只保存在当前浏览器，不上传
- AI 会自动读取你已收藏的资料库作为上下文来回答问题
- 当前模型不可用时自动切换备用模型重试

### 3. 晚安 / 早安记忆提醒（特色功能）
- 睡前在「晚安」页写下今天没做完的事
- 可选择开启提醒：第二天打开应用时自动弹出昨晚记录
- 早上 6 点为分界：6 点前写的内容归为"昨晚"
- 第二天逐件确认是否完成，未完成的可选择"带到今天"，不会自动堆积也不会丢失
- 历史记录带时间戳，可随时回看

### 4. 隐私优先设计
- 全部数据存储在 localStorage，断网可用
- API Key 只存在本地浏览器，不经过任何第三方服务器
- 深色模式自动跟随系统/应用主题

## 技术栈

- React 19 + Vite + Tailwind CSS
- 纯前端单页应用（SPA）
- 数据层：localStorage（IndexedDB 兼容层）
- AI 接口：兼容 OpenAI API 格式，用户自配
- 部署：静态托管（Netlify / GitHub Pages 等均可）

## 使用方法

1. 下载或克隆本仓库
2. 用浏览器直接打开 `index.html`
3. 进入「设置」填写你的 OpenAI 兼容 API 地址和 Key
4. 开始使用：收藏资料、AI 对话、睡前记录
